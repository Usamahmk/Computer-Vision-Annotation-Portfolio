# CVAT 2D Object Tracking & Video Annotation

## Project Overview

This portfolio project demonstrates a practical workflow for annotating and tracking objects across video frames using **CVAT (Computer Vision Annotation Tool)**. The demonstration emphasizes bounding-box placement, temporal consistency, annotation decisions, and quality review.

## Tools & Skills

- **Tool:** CVAT
- **Task:** 2D object tracking and video annotation
- **Skills:** Bounding-box annotation, tracking identities across frames, reviewing object movement, annotation decision-making, and manual quality checks

## Workflow

1. Inspect the video and identify target objects according to the task guidelines.
2. Create and adjust bounding boxes to fit the relevant objects.
3. Track the same objects across frames while maintaining consistent identities.
4. Review intermediate frames and correct boxes when needed.
5. Check annotations for missing objects, inaccurate boxes, duplicate tracks, and identity switches.

## Quality Assurance

Quality review covers bounding-box alignment, label consistency, object identity continuity, missing or duplicate annotations, and corrections to intermediate frames. Actual findings and counts will be documented in `qa-report.md` once verified.
